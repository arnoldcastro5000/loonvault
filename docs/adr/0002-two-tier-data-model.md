# Two-tier data model: Series and Pressure Metric

LoonVault distinguishes between Series (raw values fetched from BoC Valet) and Pressure Metrics (values computed internally from one or more Series). This shapes the RDS schema, the Transform Lambda's responsibilities, and the API response structure permanently. The alternative — serving only raw Series — would have been simpler, but the most analytically meaningful indicators (Real M2, yield curve spread, credit growth rate of change) are not available as pre-computed series from BoC Valet and can only exist as derived values. The two-tier model was chosen to make these indicators possible without abandoning the single data source constraint in ADR-0001.
